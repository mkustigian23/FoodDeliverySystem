This project is the semester long coding project for Bridgewater State University's COMP 390 (software engineering).
The project is created by Matthew Kustigian, Jaden Arruda, Cameron Boivin, Jennifer Chan and Dawens Fortune.
The scope is to be a food delivery system, mimicking DoorDash or Uber Eats. 
This project contains a UI from the aspect of a customer, restaurant, and the delivery driver.
